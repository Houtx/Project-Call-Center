# 系统电话托管拨号

Android 原生双卡路径可以通过 `PhoneAccountHandle` 指定卡槽；卓易通等兼容环境无法把卡槽和通话记录完整暴露给第三方 APP，因此会回退到系统电话服务选择 SIM。

这类拨号的 CallLog 可能不存在、延迟写入，或者 APP 无法读取。外呼尝试会在服务端使用两分钟的托底采集窗口。APP 从系统电话页面返回后，会等待 5 秒让系统补写 CallLog，然后再次匹配；仍没有结果时：

- 在线模式调用 `POST /mobile/call-attempts/:attemptId/unobserved`，服务端幂等地记录 `UNKNOWN` 并重新下发任务；APP 同步删除本地互斥记录。
- 离线模式在本地记录 `UNKNOWN`，将号码按既有重试次数策略放回队列或标记完成。
- 结果未知计入外呼次数，不进入接通率分母。在线模式后续收到迟到的 CallLog 结果时，服务端允许用真实结果替换超时结果。

普通 Android 路径仍保留 24 小时补采窗口，避免把正常但迟到的通话记录过早判成未知。
